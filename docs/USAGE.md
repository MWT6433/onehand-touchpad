# 使用方法（草案）

> 本文是 README 精简后迁出的详细手势表，作为后续「使用介绍富文本」的素材保留，暂时不在 README 中引用。

| 动作 | 结果 |
| --- | --- |
| 从侧边手柄向屏幕内拖动超过约 6 mm | 展开面板和光标；单击模式下只显示光标。 |
| 展开后移动手指 | 光标按位移、移动速度和灵敏度移动。 |
| 在面板内短按后原地抬起 | 在光标位置点击；落在底部箭头上的按下会改为方向滑动。 |
| 按住约 600 ms | 在光标位置长按。 |
| 长按后继续拖动（需开启选项） | 保持按下并随光标拖动；默认关闭。 |
| 短按底部左、右、下、上四格 | 从光标位置向对应方向滑动约屏幕尺寸的 35%。 |
| 点击面板下方的上下双箭头长条 | 在光标“上方”与“屏幕内侧”之间切换。 |
| 将面板拖到对侧边缘 | 打开快捷菜单；上下移动选择，松手执行。 |
| 快捷菜单里不动手指直接松手 | 切换手柄到屏幕另一侧：面板就地收回成新手柄，再在新侧展开。 |
| 快捷菜单里下移一格后松手 | 在全功能模式与单击模式之间切换。 |
| 快捷菜单里下移两格后松手 | 停止触控板并关闭无障碍服务。 |
| 菜单弹出后把手指拖离对侧边缘 | 收起菜单，回到普通拖动。 |
| 在面板外点击 | 收回面板。 |
| 长按手柄后上下拖动 | 调整手柄的垂直位置。 |
| 双击手柄 | 打开「最近使用」任务切换器；再双击或点其他位置收起。 |

## 任务切换器

双击侧边手柄，会从手柄那一侧滑出「最近使用」列表，把手放开的拇指不用移动就能选。

| 动作 | 结果 |
| --- | --- |
| 点某一行 | 切到那个应用，回到它原来的界面（不是重新启动）。 |
| 点行内最靠屏幕边缘的 × | 关闭那一个任务，列表里对应行消失。 |
| 点抽屉以外任意位置 | 收起列表，不切换也不关闭。 |

- 手柄在右侧时整行是「图标 · 名称 · ×」，手柄在左侧时整行镜像成「× · 图标 · 名称」——× 永远在靠屏幕边缘那一端，拇指根部伸过去最省力，也和"点行切换"在物理上分开。
- 当前正在使用的应用那一行整行填蓝；如果拿不到当前应用，就不高亮任何一行，避免标错。
- 关闭任务和"切回原任务"需要 Shizuku 通道；Shizuku 未就绪时列表会退化成按最近使用顺序记录的应用名，此时不显示 ×，点行仍然可以切换。

设置页里 Shizuku 是主页面单独一行（在「手柄位置」下面，不在调试抽屉里），副标题显示连接状态、点它可以去授权。
没连上时，「双击打开任务面板」下面会出现一行红字：
「没有 Shizuku：任务列表只到应用级，也没有 × 关闭按钮」。

## 演示（动图）

仓库里的 `docs/demo/` 有三段示意动画，覆盖最常用的三条路径：

| 文件 | 演示内容 |
| --- | --- |
| `pull.webp` | 从侧边手柄拉出面板 → 光标移动到按钮 → 抬手点击（含收回） |
| `swipe.webp` | 在方向条上依次点四格，画面在指针处被滑动，指针原地不动 |
| `menu.webp` | 把面板拖到对侧边缘 → 顶部弹出三行菜单 → 选中执行 |
| `switcher.webp` | 双击手柄打开「最近使用」抽屉 → 点行切换（背景换成那个应用）、点 × 关闭任务、点外部收起 |
| `adjust.webp` | 长按手柄进入调整模式（竖条变蓝）→ 上下拖动改变吸附位置 → 松手保存 |

## 桌面快捷方式

长按桌面图标，能看到两条快捷方式（动态发布，服务启动或进设置页时刷新）：

| 快捷方式 | 作用 |
|---|---|
| 触控板开关 | 开 / 关触控板，等同设置页的开关 |
| 切换左右手 | 把侧边手柄换到另一侧；面板正在外面时只记下新的一侧，等收回后生效 |
